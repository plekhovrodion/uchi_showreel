# Этап 3. Макеты: иконки, шрифты, цвета, ключевые кадры

## Материалы

- Бери шаблоны, иконки и цветовые образцы из [Figma «Контент-завод», секция «Ассеты»](https://www.figma.com/design/H05HfxWCK8Ji80GDZyPA0n/?node-id=55-2073). Шаблоны — 55:1198, иконки — 55:281, типографика — 55:2006, палитра — 55:2072. Экспортируй нужные векторы как SVG и растровые иллюстрации как PNG. Для финала используй утверждённый логотип проекта. Если его нет в доступных материалах, согласуй файл или версию финала с пользователем.
- Набирай заголовки Oceanic Grotesk Condensed ExtraBold, подписи и основной текст Factor A Regular. Загружай локальные файлы шрифтов в браузер до покадрового рендера, проверяй выбранные начертания и кириллицу. Если файлов нет, запроси OTF, TTF или WOFF2 для финальной версии. Для предварительных кадров обозначь временную замену.
- Используй ориентиры для композиции ролика: 40% оттенки фиолетового, 30% яркие основные и дополнительные цвета, 20% пастельные оттенки, 10% текст. Оцени баланс по ролику в целом, сохраняй читаемый контраст.

## Палитра

Точные значения лежат в `references/palette.json`. Используй только их. Чёрный не используй, для текста бери #362F73. Для детей и учителей только основные цвета, дополнительные (розовый, лайм, голубой) только для подростков.

## Иконки

Иконки и иллюстрации-пиктограммы делай скиллом `uchi-svg-icons` (SVG + PNG, проверка палитры скриптом). Готовые иконки из Figma (узел 55:281) экспортируй в SVG.

## Шаги

1. Разбери раскадровку и составь список ассетов на каждую сцену: иконка, иллюстрация, шаблон, паттерн, логотип.
2. Возьми ассеты из Figma по узлам, недостающие иконки нарисуй `uchi-svg-icons`. Недостающую иллюстрацию отдай этапу 4 или нарисуй векторно.
3. Положи всё в `assets/` (`icons/`, `fonts/`, `templates/`, `logo.*`, `palette.json`) и опиши в `assets/manifest.json`: файл, источник, автор или узел Figma, условия.
4. Загрузи шрифты и проверь кириллицу на строке «Абвгдеёжз Чёрное море 0123456789». Если файлов нет, запроси их и обозначь временную замену.
5. Собери три ключевых кадра 9:16 (1080 × 1920) в `keyframes/`: хук, основная сцена, финал с логотипом. Проверь баланс цветов (40% фиолетовый, 30% яркие, 20% пастельные, 10% текст), читаемость и зоны интерфейса.

## Выход

`assets/`, `assets/manifest.json`, `keyframes/*.png`.

## Гейт 2: согласование макетов

Покажи ключевые кадры в чате, обязательно скажи, какие шрифты и логотип временные. Жди явного согласования, затем:

```
python3 skills/uchi-showreel/scripts/state.py done showreel/<slug> assets
python3 skills/uchi-showreel/scripts/state.py approve showreel/<slug> gate_assets --by "<как подтвердил>"
```
