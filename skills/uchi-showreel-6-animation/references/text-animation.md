# Анимация текста

Не повторяй один приём подряд в соседних сценах. В одной сцене не больше двух приёмов. В ролике должно быть минимум четыре разных приёма.

1. **Блюр-вход** (заголовки). `blur` 24 → 0 px, `opacity` 0 → 1 за первые 60% длительности, сдвиг по Y 30–60 → 0 px, масштаб 0,92 → 1, 14–20 кадров.
2. **Побуквенная волна** (акцентное слово до 12 символов). Для каждой буквы: `blur` 12 → 0 px, сдвиг по Y 40 → 0 px, поворот ±6° → 0, задержка между буквами 2–3 кадра.
3. **Построчная маска** (многострочные заголовки). Строка выезжает из-под линии (`overflow: hidden`), сдвиг по Y 100% → 0, задержка между строками 5–8 кадров.
4. **Схлопывание трекинга** (подзаголовки). `letter-spacing` 0,3em → 0 вместе с `blur` 10 → 0 px.
5. **Панч ключевого слова.** Масштаб 1 → 1,18 → 1 пружиной за 10–14 кадров и смена цвета на акцентный. Плашку «Текст выделение» разворачивай слева, `scaleX` 0 → 1.
6. **Кинетическая типографика.** Слова появляются в такт диктору, у каждого свой размер и наклон ±3° (как в шаблоне 07). Слова заменяют друг друга: первое уходит вверх, второе входит снизу. Числа считаются счётчиком с ease-out. Ключевое слово может вырасти до размеров кадра и стать фоном следующей сцены.
7. **Выход.** `blur` 0 → 14 px, `opacity` → 0, сдвиг вверх на 20 px за 8–12 кадров, либо текст уходит вместе с переходом.

Минимум две сцены ролика строй на кинетической типографике по словам диктора. Блюр не больше 28 px. Oceanic Grotesk Condensed используй в приёмах 1, 2, 3, 5, 6, Factor A в приёмах 4 и 7.
