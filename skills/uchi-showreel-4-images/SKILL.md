# Этап 4. Изображения через ElevenLabs

## Кратко (читай это, остальное по необходимости)

- Запуск: `eleven_image.py --model gpt-image-1.5 --background transparent --aspect 1:1 --prompt "..." --out images/x.png`. Параметр `--seed` для gpt-image-* **не поддерживается** (API отвечает 422), скрипт его сам пропускает.
- Несколько картинок генерируй параллельно (`&` и `wait`), в стиле бренда: плоские цвета, без градиентов, текста и фона.
- Результат смотри одной контактной таблицей; на gpt-image бывают блики, проверь правило «без градиентов».
- Запиши `images-manifest.json` и `credits.md`; без картинок: `state.py skip ... images --note`.

## Когда нужен

**По запросу.** Если человек просит изображение (в любой момент работы, в том числе до или после этапа 4 и отдельно от ролика), сгенерируй его сразу этим скриптом, не дожидаясь очереди этапов. Покажи результат в чате и по правкам перегенерируй с другим промптом или seed. Для разовой генерации вне ролика кладка в `images/` текущей папки и запись в `images-manifest.json` тоже обязательны.

**По необходимости.** Также генерируй сам, если сцене нужна растровая иллюстрация, которой нет в Figma «Контент-завод» и которую нельзя нарисовать векторно (`uchi-svg-icons`, свой SVG, графики и схемы этапа 3). Сначала пробуй бренд-ассеты. Если изображения не нужны: `state.py skip showreel/<slug> images --note "..."`.

## Что известно из документации ElevenLabs

- Создание: `POST https://api.elevenlabs.io/v1/flows/image`, JSON с обязательными `model_id` и `prompt`.
- Необязательные поля зависят от модели: `aspect_ratio` (у многих моделей есть `9:16`), `resolution`, `seed`, `quality`, `background` (у `gpt-image-1*` значение `transparent`), `images` (референсы до 5–14 штук в зависимости от модели) и `webhook`.
- Ответ на создание: `id` и `status: "pending"`. Результат забирают отдельным GET-запросом по этому `id`.
- Список моделей меняется. Перед работой открой актуальную страницу `https://elevenlabs.io/docs/api-reference/flows/image/create.md`, выбери `model_id` и допустимые значения полей.
- Результат: `GET https://api.elevenlabs.io/v1/flows/image/{id}`. Статусы `pending`, `generating`, `completed`, `failed`. В `completed` приходят `content_url` (подписанная ссылка на файл, живёт около часа) и `content_mime_type`. Скрипт делает всё сам: создаёт генерацию, опрашивает статус и скачивает файл. Неудачные генерации не списываются.

## Шаги

1. Составь список нужных изображений по раскадровке или запросу человека: сцена, назначение, формат (обычно `9:16` для фона, `1:1` для предмета, `transparent` для вырезки).
2. Напиши промпт в стиле бренда: плоская векторная иллюстрация, насыщенные фиолетовый, коралловый и жёлтый, объёмный предмет с лёгким наклоном и боковой гранью, без фотореализма, без градиентов (только плоские цвета), без мелких паттернов и россыпи мелких объектов на фоне, без текста внутри изображения (текст набирается в анимации), без чёрного, без логотипов и реальных людей, без чужих персонажей.
3. Запусти скрипт (ключ берётся из `ELEVENLABS_API_KEY`):
   ```
   python3 skills/uchi-showreel-4-images/scripts/eleven_image.py \
     --prompt "<промпт>" --aspect 9:16 --seed 42 --out images/scene3.png
   ```
   По умолчанию модель `gemini-3.1-flash-image`. Другую задай через `--model` (список в документации). Прозрачный фон: `--model gpt-image-1.5 --background transparent --aspect 1:1`. Для проверки без сети и ключа добавь `--dry-run`. Расширение файла подменяется по типу ответа (png, jpg, webp).
4. Проверь результат глазами: стиль бренда, читаемость на фоне сцены, нет артефактов текста. Проверь палитру: цвета вне палитры перекрась или перегенерируй с другим промптом.
5. Запиши в `images-manifest.json` для каждого файла: промпт, `model_id`, `seed`, `id` генерации, дату, сцену. Сервис и модель укажи в `credits.md`.

## Выход

`images/`, `images-manifest.json`. Затем `state.py done showreel/<slug> images`.
