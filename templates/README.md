# Шаблоны «Контент-завод» (Figma H05HfxWCK8Ji80GDZyPA0n, раздел «Шаблоны»)

Формат кадра 1080×1917. Выгружено через Figma Plugin API (`exportAsync`, SVG_STRING), каждый файл проверен хешем FNV-1a от исходной строки (`verify.py`, эталоны в `hashes.json`).

- `svg/NN.svg` — исходник, текст живой (шрифты `Oceanic Grotesk Condensed`, `Factor A`), слоты: Заголовок, Подзаголовок, «Текст выделение».
- `html/NN.html` — SVG, встроенный в страницу 1080×1917.
- `png/NN.png` — превью. Шрифтов Oceanic и Factor A в окружении нет, поэтому текст в PNG набран запасным шрифтом; фигуры и цвета точные.
- Выгружено: 01, 02, 03, 04, 06, 08, 10, 11, 12, 13, 14, 15, 16.
- Не выгружено: 05, 07, 09 (встроенные растры). Нужен экспорт из Figma вручную (правый клик по фрейму, Export, SVG) или доступ к www.figma.com.
- `python3 build.py` пересобирает html и png из svg, `python3 verify.py` проверяет целостность.
